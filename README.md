# نظام جامع سعيد الجابي لإدارة الجامع والطلاب وحلقات تحفيظ القرآن الكريم

نظام ويب متكامل واحترافي مصمم وفق أحدث المعايير البرمجية لجامع سعيد الجابي ومجمع حلقاته القرآنية. يدير النظام شؤون الطلاب، وحلقات التحفيظ، والتسميع اليومي، والحضور والغياب، والمدفوعات وسندات القبض، ونقاط التميز السلوكي، وأرشيف المستندات والشهادات، مع دعم كامل للغة العربية (RTL) وتصميم إسلامي حديث.

---

## 🌟 مميزات النظام والواجهات المخصصة

تم تصميم التطبيق بواجهات وبوابات مخصصة تخدم جميع فئات المستخدمين:

1. **الصفحة الرئيسية (بوابة التسجيل العامة والاستعلام):**
   - الرابط: `https://<username>.github.io/<repo-name>/#/` أو `/#/register` أو المسار المباشر `/`
   - واجهة ترحيبية للزوار وأولياء الأمور للتعريف بحلقات جامع سعيد الجابي ومواعيدها.
   - **استمارة تسجيل إلكترونية فورية** لإلحاق الطلاب الجدد وتحديد البرنامج والحلقة.
   - **محرك استعلام فوري** لفحص حالة طلبات التسجيل السابقة برقم الجوال أو الهوية.

2. **لوحة تحكم المدير العام (`#/admin` أو `/admin` - رابط "إدارة"):**
   - الرابط: `https://<username>.github.io/<repo-name>/#/admin`
   - لوحة قيادة متكاملة وإحصائيات حية لجميع شؤون الجامع.
   - مراجعة واعتماد طلبات التسجيل وإصدار الرقم الأكاديمي الثابت التلقائي (`FRQ-2026-XXXX`).
   - الملف الشامل للطلاب (360 درجة) الذي يجمع الحفظ، الحضور، المالية، والنقاط.
   - إدارة حلقات التحفيظ والمعلمين وتوزيع المقاعد.
   - إدارة المالية والرسوم وإصدار سندات القبض المعتمدة (`REC-2026-XXXX`).
   - **قسم إعدادات النظام وسجل التدقيق (Audit Logs):** مخصص وحصري لحساب المدير العام فقط لضبط بيانات الجامع والعملة وقيم النقاط.

3. **بوابة المعلم والمشرف القرآني (`#/teacher` أو `/teacher`):**
   - الرابط: `https://<username>.github.io/<repo-name>/#/teacher`
   - عرض حلقات المعلم المكلف بها وجدولها ومواعيدها.
   - كشف بطلاب حلقة المعلم وإجراءات سريعة لرصد التسميع اليومي والمراجعة.
   - تحضير الحضور والغياب ومنع تكرار السجلات.
   - منح نقاط التميز والمكافآت القرآنية والسلوكية لطلاب حلقته.

4. **بوابة الطالب (`#/student` أو `/student`):**
   - الرابط: `https://<username>.github.io/<repo-name>/#/student`
   - بطاقة الطالب الأكاديمية الرقمية المزودة بالباركود وبيانات الطوارئ قابلة للطباعة.
   - خطة الغد والواجب القادم وتوجيهات المعلم.
   - سجل التسميع والمراجعة مع تقييم النجوم للإتقان وأحكام التجويد.
   - كشف الحضور والغياب ونسبة الالتزام.
   - رصيد نقاط التميز والرتبة القرآنية وأرشيف الشهادات وتنزيلها.

5. **بوابة ولي الأمر (`#/parent` أو `/parent`):**
   - الرابط: `https://<username>.github.io/<repo-name>/#/parent`
   - البحث عن الأبناء برقم الجوال أو الهوية واستعراض ملفاتهم.
   - متابعة الحفظ والتسميع اليومي وملاحظات معلم الحلقة.
   - كشف الحضور والانضباط اليومي ونسبة المواظبة.
   - كشف الرسوم والاشتراكات وسندات القبض المسددة مع إمكانية طباعتها فوريًا.

6. **بوابة المحاسب المالي (`#/accountant` أو `/accountant`):**
   - الرابط: `https://<username>.github.io/<repo-name>/#/accountant`
   - لوحة إحصائيات مالية (الإيرادات المحصلة، الأرصدة المتبقية، الخصومات والإعفاءات).
   - إصدار سند قبض إلكتروني فوري وطباعته مع الختم الرسمي.
   - كشف كامل بسندات القبض مع إمكانية الفلترة والبحث وتصدير تقرير CSV.
   - قائمة الطلاب المستحق عليهم رسوم ومبالغ متأخرة.

7. **بوابة شؤون الطلاب والتسجيل (`#/staff` أو `/staff`):**
   - الرابط: `https://<username>.github.io/<repo-name>/#/staff`
   - مراجعة وفحص طلبات التسجيل الواردة وقبولها أو رفضها مع تسكين الحلقة.
   - سجل الطلاب الشامل مع تعديل البيانات وطباعة البطاقات.
   - أرشيف المستندات والوثائق الثبوتية وإمكانية رفع ملفات جديدة.

## 🚀 النشر على GitHub Pages

المشروع مبني كواجهة ثابتة أحادية الصفحة (Static Single Page Application - SPA) باستخدام **React 19** و **Vite**، ولا يتطلب خادم Node.js خلفي في بيئة التشغيل، حيث يتصل مباشرة بخدمات Firebase السحابية عبر مفاتيح العميل العامة الآمنة المحمية بقواعد أمان Firestore.

### خطوات تفعيل النشر التلقائي عبر GitHub Actions:

1. **رفع المشروع إلى مستودع GitHub:**
   ```bash
   git add .
   git commit -m "إعداد نظام الفرقان للنشر على GitHub Pages"
   git push origin main
   ```

2. **تفعيل إعدادات Pages في المستودع:**
   - ادخل إلى المستودع على GitHub: `https://github.com/<username>/<repo-name>`
   - اذهب إلى **Settings** (الإعدادات) > **Pages** (في القائمة الجانبية).
   - تحت قسم **Build and deployment**:
     - اختر **Source**: `GitHub Actions`.

3. **سير العمل التلقائي (GitHub Actions Workflow):**
   - تم إنشاء ملف سير العمل في المسار: `.github/workflows/deploy.yml`.
   - عند أي دفع جديد (`push`) إلى الفرع `main`، سيقوم GitHub تلقائياً ببناء التطبيق ورفعه ونشره على الرابط:
     `https://<username>.github.io/<repo-name>/`

4. **معالجة المسارات والروابط (SPA & 404):**
   - تم ضبط `base: './'` في `vite.config.ts` لضمان عمل ملفات JS وCSS والخطوط تحت أي مسار فرعي للمستودع.
   - تم إضافة ملف `public/404.html` لتحويل المسارات المباشرة إلى التطبيق بسلاسة تامة دون أخطاء 404.
   - يستخدم النظام التوجيه بالهاش (Hash Routing مثل `#/admin`, `#/student`, `#/teacher`) لضمان عمل الروابط وإعادة تحميل الصفحة بنسبة 100% على خوادم GitHub Pages الثابتة.

## 🔒 إعدادات Firebase والمصادقة

1. **إضافة نطاق GitHub Pages إلى النطاقات المصرح بها (Authorized Domains):**
   - افتح [Firebase Console](https://console.firebase.google.com).
   - انتقل إلى مشروعك > **Authentication** > **Settings** > **Authorized domains**.
   - اضغط على **Add domain** وأضف نطاق GitHub Pages:
     `username.github.io`
   - هذا يضمن عمل تسجيل الدخول بحساب جوجل (`signInWithPopup`) دون أي قيود نطاق.

2. **قواعد الأمان (Firestore Rules):**
   - تم ضبط ونشر ملف `firestore.rules` لحماية كافة المجموعات ومنع التعديلات غير المصرح بها على الخادم مباشرة:
     - مستندات الإعدادات والمديرين لا يعدلها إلا المدير العام.
     - المدفوعات محصورة بالمحاسب والإدارة.
     - رصد التسميع والحضور مسموح للمعلمين والإدارة.
     - السجلات المالية وسجلات الطلاب معزولة ومحمية.
